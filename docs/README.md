# 이미지와 검증 문서

`screenshot.png`는 공개본의 가상 샘플 UI를 실제 로컬 Chrome에서 캡처한 이미지입니다.
사용자의 개인 루틴·브라우저 계정 화면을 포함하지 않습니다.

`user-example-redacted.png`는 사용자가 공개를 승인한 실제 사용 이미지의 가림 처리본입니다.
계정·아티팩트 UI, 날짜, 제품명·디바이스명, 사용 지시·관리 문구를 불투명하게 가렸습니다.
원본과 원본 메타데이터는 포함하지 않습니다. 실제 사용 사실만 설명하며 효과·안전성을 검증한 이미지는 아닙니다.

검증 범위는 [TESTING.md](TESTING.md)에 기록합니다.
