# 검증 범위

검증일: 2026-10-07. 개인정보 없는 공개 샘플을 로컬 Chrome에서 확인했습니다.

## 웹 UI에서 직접 확인한 항목

- 오늘의 아침 항목 체크 → 개수 증가 → 새로고침 후 상태 유지
- 다른 요일 미리보기 → 체크박스 없음 → 오늘로 복귀 후 체크 상태 유지
- 아침·저녁 탭 전환, 제품 목록 펼치기 및 다 쓴 항목 개수 제외
- 420px 폭에서 가로 넘침 없음, 759px에서는 탭, 760px에서는 두 시간대 표시
- 현재 환경의 어두운 화면 렌더링과 실제 샘플 스크린샷
- 테스트 중 브라우저 콘솔 오류·경고 없음

## 코드 로직 검사

Node.js의 격리된 VM과 모의 DOM·시계·저장소로 18개 검사를 통과했습니다.
인라인 스크립트 실행, 15시 경계, 0·24시 설정, 잘못된 설정의 기본값,
자동·수동 탭 유지, 자정 새로고침 요청, 이전 날짜 체크 무시, 손상된 저장소,
표시 텍스트 HTML 이스케이프, 2주·4주 교체, 연말 ISO 주 번호, 제품 수,
누락 요일, 저장소 차단, 외부 리소스·네트워크 호출 부재를 검사했습니다.

VM 검사는 실제 브라우저의 시간·날짜 변경 테스트를 대체하지 않습니다.
밝은 화면의 CSS 규칙은 정적으로 검토했으며 운영체제 테마 변경은 테스트하지 않았습니다.

## Windows 런처

두 PowerShell 스크립트의 구문 파서 오류는 0개였습니다. BAT·PowerShell 내용을 정적으로 검토했고
실행 정책 우회 옵션을 제거했습니다. 자동시작 파일은 기존 바로가기를 덮어쓰지 않도록 했습니다.

**실제로 실행하지 않은 항목:** 런처, Win32 창 고정·위치·크기 조정, Startup 바로가기 생성·해제.
자동시작 설치, Windows 보안·실행 정책 변경, 소프트웨어 설치는 수행하지 않았습니다.
